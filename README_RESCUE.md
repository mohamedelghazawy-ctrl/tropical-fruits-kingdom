# وضع إنقاذ ملكة الفواكه
- `rescue/RescueEngine.kt`: محرك نقي (بلا Compose) — بذور تنساب، جذع، بذور ثقيلة، ثعبان. اختبار: `RescueEngineTest`.
- `rescue/RescueViewModel.kt` + `ui/screens/RescueScreen.kt`: الرسوم والإدخال. الزر في القائمة الرئيسية (`rescue_button`).
- الملكة: `res/drawable-nodpi/queen_*.webp`. خمسة مستويات (بذور ثقيلة، جبل عالي، عاصفة الثعبان) مع تصدّع الحجارة المحاصَرة تلقائيًا عند انعدام الحركات.
- ملاحظة: لم يُبنَ مشروع Gradle في بيئة العمل (لا يوجد Android SDK)، فقط المحرك مُختبر؛ طبقة Compose لم تُصرَّف بعد.
- النسخة الويب: `web/index.html` (ذاتية الاكتفاء).

## تحديث: الإنقاذ على الخريطة + الجوائز + الإعلانات
- عقدة إنقاذ بعد كل ٥ جزر (تُفتح بعد نجاح الجزيرة ٥k). أُزيل زر الإنقاذ من القائمة الرئيسية.
- جائزة الفوز: إعصار ثم مطرقة بالتناوب، ومضاعفتها (+١) بإعلان. تُحفظ في مخزون الأدوات (`inv_*` في SharedPreferences).
- الخسارة (إنقاذ أو جزيرة عادية): إعلان → الثعبان يتراجع خطوتين (إنقاذ) / ٥ حركات (جزيرة)، مرة لكل محاولة، أو استسلام للقائمة الرئيسية.
- `ads/RewardedAds.kt`: مزوّد محاكاة (٥ ثوانٍ). لاستخدام AdMob: نفّذ `RewardedAdProvider` وعيّن `RewardedAds.provider`.
- لم يُبنَ مشروع Gradle هنا؛ طبقة Compose/ViewModel غير مُصرَّفة.
